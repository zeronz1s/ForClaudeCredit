# Rocket League Recreation (Roblox)

Luau source for a Rocket League recreation in Roblox. Every script is stored as a
`.txt` file whose path mirrors where it goes in Studio, for example
`ServerScriptService/CarController.txt` goes in **ServerScriptService** as a Script
named `CarController`. The header comment at the top of each file names its class
and exact parent.

Shared rules every system follows live in `ReplicatedStorage/RLShared.txt`:
world scale (RL units to studs), gravity, CollectionService tags, remote names
and folder names.
